# Labyrinth (3D)

## Game Description

This is a first-person 3D maze, recreated in Unity 6.3 (URP) for the WebGL platform.

The project is an **independent reimplementation inspired by the Labyrinth project by Sankek**.
The original repository did **not contain an explicit license** at the time this work was started.
This codebase was written separately and does not reuse the original source code.

Unlike the original, nothing was done manually. The project was created and brought to MVP
in just a few hours using AI-assisted development tools (Qwen3, Claude Code, ChatGPT).
Vibecode.

---

## System Requirements

- Any HTTP server
- Desktop browser (keyboard + mouse required)

---

## Gameplay Overview

The core gameplay concept is inspired by the original idea.

- You control the camera (the “player”) inside a large labyrinth built from colored walls and a solid floor.
- The goal is free exploration.
- There are no enemies, objectives, or timers — this is a calm walk through an abstract space.
- Controls work **only in desktop browsers**. Mobile devices are not supported.

---

## How to Play

### Movement
- **W** — move forward  
- **S** — move backward  
- **A** — move left  
- **D** — move right  
- **Q / E** — fly down / up  
- **Mouse** — look around  
- **LMB** — make graffiti  

### Other
- **ESC** — pause  
- **F** — restart (not implemented yet)
